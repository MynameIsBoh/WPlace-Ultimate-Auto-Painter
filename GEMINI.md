# Wplace AutoBot Rules

## §1 — Versioning Rule (Update Version)
Every time a modification or update is made to the `BOT WPLACE V1` script, you **MUST** automatically increment the version number in the Userscript header (`@version`). 
- Increment the patch version (e.g., `6.0.2` -> `6.0.3`) for small bug fixes.
- Increment the minor version (e.g., `6.0.3` -> `6.1.0`) for new features.
Do not ask for permission, just update it in the same set of changes.
